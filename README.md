# Financial Performance Analysis

A data analysis project using Python and Google Colab to explore financial sales data and extract meaningful business insights through cleaning, analysis, and visualization.

---

## Overview

This project analyzes a financial dataset to understand sales performance across products, regions, and customer segments. It focuses on applying basic data analysis techniques to real-world structured data.

---

## Objectives

- Clean and prepare financial sales data  
- Analyze sales and profit trends  
- Identify top-performing products and regions  
- Explore the effect of discounts on performance  
- Visualize key insights using charts  

---

## Key Insights

- Government segment generated the highest profit  
- Paseo was the top-performing product  
- United States had the highest revenue contribution  
- Medium discount levels had a strong impact on sales  

---

- Python  
- Google Colab  
- Pandas  
- NumPy  
- Matplotlib  
- Seaborn
